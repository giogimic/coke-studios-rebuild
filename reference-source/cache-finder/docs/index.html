Your old computer might still have Coke Studios on it.

Coke Studios (Coke Music, later MyCoke) closed in December 2007. Fans have since saved most of it, including the rooms, the furniture, the V-egos and the website games, but some pieces are still missing. Every time you played, Shockwave downloaded the game through your web browser, and browsers kept copies. The missing pieces may still be on an old PC or hard drive, and a free tool can find them for you.

Free, open source, about 110 KB. Nothing to install, and it never connects to the internet.

How to help

Run it

Double-click the program and choose 1. If the computer is too old to download it, copy it over on a USB stick. Old hard drives can be searched from any computer through a USB adapter.

Wait

It checks every drive and lists anything it finds as it goes. Most computers take a few minutes. Searching deleted files (option 2) can take an hour or more.

Send the zip

It makes one .zip next to the program. Open a new issue and drag the zip in, even if it found only a little. Issues are public; the zip holds only game files.

Windows may say the program is unrecognised, because it isn't signed. Click More info, then Run anyway. On a Mac, right-click it and choose Open.

    What it looks at

    It recognises Shockwave casts and movies (.cct, .dcr, …) and Flash movies by their contents, whatever they are called. It reads Internet Explorer's and Firefox's cache indexes to learn which address each file came from and when. It looks inside cache files, temp files and disk images for game files packed into them. And it collects the game's old web addresses from browser history, which show what existed even where the files are gone.

    Your privacy

    • It only reads. Nothing is changed or deleted, and nothing is sent anywhere. You decide whether to send the zip.
    • The zip holds only game files, and every one is listed in the report.txt beside it, so you can check before sending.
    • Your Windows user name is removed from the report. Web addresses lose everything after ?, where session ids lived.
    • Cookies are never read. Pictures with "coke" in the name are listed, but never copied.

    Looking by hand

    Look for files ending in .cct, .dcr or .swf, and anything with [1] in its name. On Windows, turn on hidden files first.

    Windows 2000/XPC:\Documents and Settings\you\Local Settings\Temporary Internet Files\Content.IE5\

    Questions

    Is it safe to run?

    It only reads files and never goes online. The source code is public, and every release is built from it by GitHub.

    It found nothing. Is that useful?

    Yes, thank you. If the computer was used for Coke Studios and has been cleaned up since, try option 2: deleted files often stay on the disk for years.

    It found files "the archive already has". Should I still send them?

    Please do. Send the zip anyway. The report records where and when your copies were saved, which helps date the archive's.

    My old PC doesn't turn on any more.

    The hard drive inside probably still works. A USB-to-IDE/SATA adapter costs a few dollars and lets any computer search it.

    Can it read Mac OS 9 or very old Macs?

    Not directly, but it can search their drives when they are connected to a newer Mac, or from a disk image.
