# Minigame evidence and original rules

Preserve each game's version, lobby, instructions, art, audio and rewards separately. A generic game with the same theme does not establish parity.

## Uncover the Music: a concrete local rules source

Source: sources/uncover-the-music/_resources/_other/html/RevealChallengeRules.htm, preserved inside markhughes/uncover-the-music. Associated styles07.css references 2007 website assets; that alone does not date the rules document. The HTML presents itself as official rules, but the archive capture URL/date has not been authenticated. These are direct observations of this preserved copy, not independently verified claims about every edition.

| Topic | Rule stated in the preserved document |
|---|---|
| Entry | Registered MyCoke account; choose a room after viewing occupants and count |
| Players | Minimum 3, maximum 5 |
| Starting | First entrant chooses when to start; 30-second decision period after at least 3 are present |
| First turn / order | First player chosen randomly; play proceeds counterclockwise |
| Board | 24 squares: 11 matching pairs, one Wild Card and one Pass Card |
| Turn | Up to two tile selections within 15 seconds; incomplete selection forfeits the turn |
| Match | Pattern and associated music match; award 1 Decibel; remove matched tiles; same player continues |
| Wild Card | Can match another card; removed on first reveal |
| Pass Card first | No second selection; next player begins |
| Pass Card second | Turn ends; first tile stays on board |
| Normal end | All pairs matched |
| Winner | Most matched pairs; additional 60-Decibel bonus |
| Tie | Share the 60-Decibel bonus equally among tied leaders |
| Daily earning limit | 300 Decibels for this game per day, described as midnight to 11:59 p.m. |
| Crediting | Add earnings on completion |
| Dropouts | Fewer than 3 players terminates play; earned Decibels credited, no winner bonus |
| Other early end | No 60-Decibel bonus |

**Unresolved even with this document:** timezone, rounding of shared bonuses, exact Wild Card edge cases, reconnect policy, what happens when the initiating player leaves before starting, and whether later versions changed these rules. Do not infer these from generic memory-game behavior.

This source is especially useful for auditing a two-player implementation, fixed turns, different board size, invented rewards or immediate per-match persistence. Those would need separate historical evidence.
