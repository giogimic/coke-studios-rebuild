## Specific gaps reported by the preservation project

The local cache-finder README identifies earlier clients, old public-room descriptions, theatre/Wal-Mart material, a Shark Tale background, a rooftop navigator icon, game-specific missing art/audio, saved mixes, some avatar palettes and dynamic promotional content as wanted. Treat this as the maintainer's archive status, not a worldwide finding.

The known-file index contains 446 fingerprint/name/size entries. Match recovered bytes against it, but preserve URL, cache metadata and timestamps even when the content is already known. Original provenance can resolve a version conflict even when another file has the same bytes.

Do not run a machine-wide cache scan or submit personal files under this website-research task. Public archives and preserved project folders are the authorized acquisition scope here.

## Current access limits

- Direct HTTP downloads fail with ENOTFOUND in the execution environment. The collector records this and stops rather than creating fake image/HTML files.
- The web research tool can read some pages and resolve image URLs, but returned no image bytes for the original-developer screenshots.
- Several archive/wiki requests were inaccessible or blocked. Blocked sources are recorded; no authentication, access-control bypass or gated downloads were attempted.
- The 38 queued URLs are known leads, not 38 completed captures. Retrieval logs and hashes identify actual saves.
- Existing local screenshots and exported assets remain available in the gallery. Most corpus expansion this pass is indexing and research over material already downloaded.
