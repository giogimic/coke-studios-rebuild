# Visual reference contact sheet

All images below were already preserved in sources/cache-finder/docs/img. They are community-preserved screenshots/illustrations, not newly downloaded originals. Capture dates and original URLs are not authenticated here. File hashes and dimensions are in [visual-references.json](generated/visual-references.json).

Four references were visually inspected during this research. The rest are catalogued as candidates, not claimed to have been analyzed.

## Early website

![Early Coke Music website](../../sources/cache-finder/docs/img/cokemusic-2002.webp)

Observed: left account portrait and login fields; separate poll; top Home / Launching Pad / Coke Studios / Create Your Demo / Coke FM / Downloads / Help strip; large music/studios tiles and postcard/invite actions. The “2002” label comes from the preserved filename. Detailed breakdown: [website structure](WEBSITE-STRUCTURE.md).

## Beta-labelled in-game screen

![Beta-labelled room screen](../../sources/cache-finder/docs/img/beta-ingame.webp)

Observed: dark tiled plaza, tram, performance stage, bottom Speak/Shout controls and a row of circular toolbar icons. A BETA mark is visible near the lower-right branding. This is a small raster reference; its dimensions do not establish the original logical stage size. Exact build/date unknown.

## V1-labelled Alaska screen

![V1-labelled Alaska room](../../sources/cache-finder/docs/img/v1-alaska.webp)

Observed: snow/ice isometric scene, water and DJ platform, avatars queuing, colored name/chat boxes, bottom Speak/Shout toolbar, separate Thumbs down / Thumbs up controls, and a Now Playing display above them. The source image measures 760 x 520; that alone does not identify the same client as later exports. Text/raster detail must be compared at native scale.

## Shark Tale website branch

![Shark Tale promotional page](../../sources/cache-finder/docs/img/sharktale-site.webp)

Observed: promotion title, code-entry invitation, member/register callout, separate Whale Wash Builder and Whale Wash Activity links, and a 2004 copyright footer. Missing images are visible in the capture. Do not recreate broken resources as intended design or merge this branch into every home page.
